このインストール手順書では、全機能の共通基盤となる初期セットアップを行います。

セットアップ開始：ターミナルで install.sh を実行する

フォルダを配置してターミナルでコマンドを実行するだけで全 12 ステップが始まります

install.sh は、このツールのセットアップに必要な全 12 ステップを自動で案内するインストーラーです。

ターミナルでコマンドを実行するだけで順番に処理が進みます。所要時間の目安は 15〜20 分です。

  • STEP 1・4・5・6・9・10 はすべて自動処理（待つだけ）
  • STEP 7 のみ Enter を押す操作が必要
  • STEP 2・3・8・11・12 は画面の案内に従って手動で設定

① フォルダを配置する

受け取った nyseo-internal-link-agent フォルダを、恒久的な場所に移動してください。

推奨パス
~/Documents/nyseo-internal-link-agent/
⚠️
以下の場所への配置は避けてください：
・デスクトップ・ダウンロード（install.sh が途中で警告を出します）
・iCloud Drive・Dropbox などのクラウド同期フォルダ（競合が起きる場合があります）

② ターミナルを開いて install.sh を実行する

Spotlight（Command + Space）で「ターミナル」と検索して開き、以下を実行してください。

ターミナル
cd ~/Documents/nyseo-internal-link-agent
bash install.sh
✅
以下のような画面が表示されれば正常に起動しています。

install.sh の 12 ステップ概要

install.sh を起動すると、以下の順番で自動的に進みます

操作が必要なのは STEP 7 の操作（Enter キー）と、STEP 2・3・8・11・12 の手動入力のみです。それ以外はすべて自動で完了します。

STEP 内容 操作
1Python のインストール確認自動確認
2Chrome・Claude 拡張機能の確認手動確認
3Cowork（Claude Desktop Pro）の確認手動確認
4Claude CLI ログイン確認自動確認
5プロジェクトフォルダの確認・登録自動確認

1

Python のインストール確認

すでにインストール済みの場合はスキップ可

ターミナルで以下を実行してください。

ターミナル
python3 --version
✅
OK：Python 3.11.x のようなバージョンが表示されます → そのまま install.sh が進みます。
⚠️
「command not found: python3」と表示される場合：
python.org から macOS 版インストーラー（.pkg）をダウンロードして実行してください。
インストール後はターミナルを一度閉じて再度開いてから python3 --version を再確認してください。
2

Google Chrome と Claude 拡張機能の確認

Cowork が Chrome を操作して処理を起動するために必要です

Chrome のインストール確認

Google Chrome がインストールされているか確認してください。

  • Spotlight（Command + Space）で「Chrome」を検索して起動できればインストール済みです
  • インストールされていない場合は google.com/chrome から .dmg をダウンロードしてインストールしてください

Claude Chrome 拡張機能のインストール

Cowork が Chrome を操作するために必要な公式拡張機能です。

  1. Chrome を開く
  2. Chrome ウェブストアで「Claude」を検索する（下のリンクから開けます）
  3. 「Claude」（Anthropic 製）を選んで「Chrome に追加」をクリック
  4. 確認ダイアログで「拡張機能を追加」をクリック
  5. Chrome の右上に Claude のアイコン（橙色）が表示されれば完了
Chrome ウェブストア検索 URL
https://chromewebstore.google.com/search/Claude
⚠️
インストール後に以下の設定を必ず行ってください：
Cowork の画面で 設定 →「Claude in Chrome」→「すべてのサイト」のデフォルト項目で「拡張機能を許可」を選択する。
この設定をしないと内部リンクエージェント実行時に接続エラーになります。

Claude Desktop Pro（Cowork）の確認

チャットからエージェントを実行するためのアプリです

Cowork（Claude Desktop Pro）がインストールされており、起動できることを確認してください。

  • Spotlight で「Claude」を検索して起動できるか確認
  • インストールされていない場合は claude.ai/download から .dmg をダウンロードしてインストールしてください
  • Anthropic のアカウントでログインしてください

Claude CLI ログイン確認

install.sh が自動で確認します

install.sh が Claude CLI（claude コマンド）の場所を自動で検索し、実際にプロンプトを送信してログイン済みかどうかを確認します。検索場所は以下の順番です。

  • ~/.claude/local/claude（Cowork が自動インストール）
  • ~/Library/Application Support/Claude/claude-code/
  • /usr/local/bin/claude、/opt/homebrew/bin/claude
✅
ログイン済みであれば自動で次のステップへ進みます。
━━━━━━ [4/12] Claude CLI ログイン確認 ━━━━━━
✔ claude を発見: ~/.claude/local/claude
ログイン状態を確認中...
✔ Claude CLI のログインを確認しました

未ログインと判定された場合

以下のメッセージが表示されたら、ログイン操作を行ってください。

⚠ Claude にログインしていません。ログインが必要です。
 
  【手順】
  1. 別のターミナルウィンドウを開いて以下を実行：
  ~/.claude/local/claude
  2. 起動後に /login と入力して Enter

Google サービスアカウント JSON の自動配置

install.sh が自動でコピーします

受け取ったフォルダ内の secrets/ に JSON ファイルが含まれている場合、install.sh が自動的に ~/.secrets/ へコピーします。

nyseo-internal-link-agent/
└── secrets/
　　 └── nyseo-agent-xxxxxxxx.json　← ここに入っていれば OK
✅
JSON ファイルが secrets/ フォルダ内にあれば、install.sh が自動的に ~/.secrets/ へコピーします。手動での操作は不要です。
⚠️
JSON ファイルが見つからない場合：ダウンロードフォルダまたはデスクトップに配置すると install.sh が自動検出してコピーします。見つからない場合はパスを手動入力する画面が表示されます。

環境変数の設定

~/.zshrc に JSON パスを自動記録します

install.sh が ~/.zshrc に GOOGLE_SERVICE_ACCOUNT を自動で書き込みます。

Google サービスアカウントのパス確認

STEP 6 でコピーした JSON のパスが自動表示されます。合っていれば Enter を押すだけです。

━━━━━━ [7/12] 環境変数の設定 ━━━━━━
 
[7-1] Google サービスアカウント JSON のパス設定
デフォルト: /Users/<ユーザー名>/.secrets/agent-xxxxxxxx.json

✔ ファイルを確認しました
✔ GOOGLE_SERVICE_ACCOUNT を ~/.zshrc に設定しました
ℹ️
設定した環境変数はターミナルを再起動後に反映されます。install.sh が完了したら source ~/.zshrc を実行するか、ターミナルを一度閉じてください。
8

WordPress サイト情報の設定

WordPress 自動反映機能を使う場合に設定します（スキップ可）

WordPress REST API で記事を更新するため、サイトの URL・ユーザー名・アプリケーションパスワードを入力します。入力した情報は ~/.secrets/nyseo_sites.json に安全に保存されます。

  1. WordPress サイト URL を入力する（例：https://example.com）
  2. WordPress ユーザー名 を入力する（ログイン名）
  3. アプリケーションパスワード を入力する（スペース区切りの文字列）
  4. 複数サイトを登録する場合は「Y」を入力して繰り返す
ℹ️
WordPress を使わない場合は N を入力してスキップできます。後から bash install.sh を再実行して追加することも可能です。

アプリケーションパスワードの発行手順

  1. WordPress 管理画面 → 「ユーザー」→「プロフィール」を開く
  2. ページ下部の「アプリケーションパスワード」セクションまでスクロール
  3. 任意の名前を入力して「新しいアプリケーションパスワードを追加」をクリック
  4. 表示されたパスワード（スペース区切り）をコピーして入力する
⚠️
アプリケーションパスワードは発行時の1回しか表示されません。必ずコピーしてから入力してください。

11

Cowork プロジェクトの作成

install.sh が指示文を自動生成・クリップボードにコピーします

install.sh がプロジェクトフォルダのパスを埋め込んだ指示文を自動生成し、クリップボードにコピーします（pbcopy 使用）。以下の手順でプロジェクトを作成してください。

  1. Cowork（Claude Desktop Pro）を起動する
  2. 左サイドバーの「Projects」をクリックする
  3. 「+ New project」をクリックする
  4. プロジェクト名に「内部リンクエージェント」と入力して作成する
  5. 「Project instructions」の入力欄を開く
  6. ターミナルに表示された指示文を全文コピーして貼り付ける（Command + V）
    クリップボードに自動コピーされている場合はそのまま貼り付けできます
  7. 保存する
ℹ️
指示文にはランナーサーバーの起動方法・WP 挿入の手順・各パラメータの説明が含まれています。Cowork はこの指示文をもとにエージェントを正しく操作します。

Google Spreadsheet の準備

ツールが読み込む Spreadsheet を新規作成して共有します

① Spreadsheet を新規作成する

  1. ブラウザで Google ドライブ（drive.google.com）を開く
  2. 「+ 新規」→「Google スプレッドシート」をクリック
  3. シート名は任意でOK（例：内部リンク管理）

② 列構成を確認する

以下の列順になっているか確認してください。

列内容備考
ANO記事番号
B記事URL処理対象のURL
CメインKWキーワード（空欄可）
D発リンク数
E被リンク数1 以下の記事が処理対象
Fクリック数
G表示回数
H〜M出力欄ツールが自動入力（空欄のままでOK）
⚠️
列の順番が違う場合は列を並び替えてから次へ進んでください。

③ サービスアカウントに編集権限を付与する

install.sh が自動的にサービスアカウントのメールアドレスを表示し、クリップボードにコピーします。

  1. Spreadsheet 右上の「共有」ボタンをクリック
  2. 表示されたメールアドレスを入力して追加する（Command + V で貼り付け）
  3. 権限を「閲覧者」→「編集者」に変更する
  4. 「送信」をクリック

④ Spreadsheet の URL をコピーする

ブラウザのアドレスバーの URL をコピーしておいてください。

✅
この URL を Cowork のチャットに貼り付けると処理が始まります。セットアップはこれで完了です。

このツールの仕組みと概要

セットアップ前に全体像を把握してください

何をするツールか

Cowork（Claude Desktop Pro）と連携し、SEO 改善作業を自動化するエージェント群です。
このインストール手順書では、全機能の共通基盤となる初期セットアップを行います。

機能概要手順書
内部リンクエージェント 被リンク不足の記事に対して、サイト内の内部リンク候補を AI が自動提案。結果を Spreadsheet の H〜M 列に書き込む guide-internal-link.html
WordPress 自動反映機能 Spreadsheet の承認済み候補を WordPress 記事へ自動挿入する guide-wp-insert.html

セットアップ開始：install.bat を起動する

zip を展開してフォルダを配置し、install.bat をダブルクリックするだけで全 11 ステップが始まります

install.bat は、このツールのセットアップに必要な全 11 ステップを自動で案内するインストーラーです。

ダブルクリックするだけで PowerShell が開き、順番に処理が進みます。所要時間の目安は 15〜20 分です。

  • STEP 1〜7・9・10 はすべて自動処理（待つだけ）
  • STEP 7 のみ Enter を 2 回押す操作が必要
  • STEP 8・11・12 は画面の案内に従って手動で設定

このページでは、zip 展開から各ステップの詳細まで順番に説明します。

① zip を展開してフォルダを配置する

受け取った nyseo-internal-link-agent.zip を右クリック →「すべて展開」で展開してください。

配置場所について

このツールは内部でコマンドを実行するため、フォルダのパスに日本語や半角スペースが含まれるとエラーが発生します。以下の場所への配置を推奨します。

推奨パス
C:\tools\nyseo-internal-link-agent\

C:\tools\ フォルダが存在しない場合は、エクスプローラーで C:\ を開いて新規フォルダを作成してください。

⚠️
以下の場所への配置は避けてください：
・デスクトップ・ドキュメント・ダウンロード（Windowsアカウント名が日本語の場合、パスに日本語が混入する）
・OneDrive 管理下のフォルダ（クラウド同期との競合が起きる場合がある）
・ネットワークドライブ・USB メモリ

② install.bat をダブルクリックして起動する

展開した nyseo-internal-link-agent フォルダを開き、install.bat をダブルクリックしてください。PowerShell が自動で起動してインストールが始まります。

✅
黒いウィンドウ（PowerShell）が開き、インストーラーのメッセージが表示されれば正常に起動しています。
⚠️
「このアプリがデバイスに変更を加えることを許可しますか？」と表示される場合：
「はい」をクリックしてください。

「Windows によって PC が保護されました」と表示される場合：
「詳細情報」→「実行」をクリックしてください。

1

Python のインストール確認

すでにインストール済みの場合はスキップ可

スタートメニューから「PowerShell」を検索して開き、以下を実行してください。

PowerShell
py --version
✅
OK：Python 3.11.x のようなバージョンが表示されます → ステップ 2 へ進んでください。
⚠️
「py は認識されていません」と表示される場合：
python.org からインストーラーをダウンロードして実行してください。
インストール画面で 「Add Python to PATH」のチェックを必ず入れてください。
インストール後は PowerShell を一度閉じて再度開いてから py --version を再確認してください。
2

Google Chrome と Claude 拡張機能の確認

Cowork が Chrome を操作して処理を起動するために必要です

Chrome のインストール確認

Google Chrome がインストールされているか確認してください。

  • スタートメニューで「Chrome」を検索して起動できればインストール済みです
  • インストールされていない場合は google.com/chrome からダウンロードしてください
ℹ️
Chrome は 通常起動できる状態（ログインなしでも可）であれば問題ありません。Cowork が自動操作するため、普段 Chrome をメインブラウザとして使っていなくても構いません。

Claude Chrome 拡張機能のインストール

Cowork が Chrome を操作するために必要な公式拡張機能です。

  1. Chrome を開く
  2. Chrome ウェブストアで「Claude」を検索する（下のリンクから開けます）
  3. 「Claude」（Anthropic 製）を選んで「Chrome に追加」をクリック
  4. 確認ダイアログで「拡張機能を追加」をクリック
  5. Chrome の右上に Claude のアイコン（橙色）が表示されれば完了
Chrome ウェブストア検索 URL
https://chromewebstore.google.com/search/Claude
✅
拡張機能バーに Claude のアイコン（橙色）が表示されていればインストール済みです。すでにある場合は何もしなくて構いません。
⚠️
Cowork の「Claude in Chrome」機能は この拡張機能がなければ動作しません。必ずインストールしてください。
3

Claude Desktop Pro（Cowork）の確認

チャットからエージェントを実行するためのアプリです

Cowork（Claude Desktop Pro）がインストールされており、起動できることを確認してください。

  • スタートメニューで「Claude」を検索して起動できるか確認
  • Anthropic のアカウントでログインしてください
  • インストールされていない場合は管理者に確認してください
ℹ️
Cowork には 内部リンクエージェント プロジェクトが設定済みである必要があります。プロジェクトの作成は install.bat の STEP 10 で案内します。

Claude CLI ログイン確認

install.bat が自動で確認します

install.bat が Claude CLI（claude コマンド）の場所を自動で検索し、実際にプロンプトを送信してログイン済みかどうかを確認します。

✅
ログイン済みであれば自動で次のステップへ進みます。
━━━━━━ [4/11] Claude CLI ログイン確認 ━━━━━━
ログイン状態を確認中...
✔ Claude CLI のログインを確認しました

未ログインと判定された場合

以下のメッセージが表示されたら、ログイン操作を行ってください。

⚠ Claude にログインしていません。ログインが必要です。
 
  【手順】
  1. 別の PowerShell ウィンドウを開いて以下を実行：
  & "C:\...\claude.exe"
  2. 起動後に /login と入力して Enter
  3. ブラウザで Claude アカウントにログイン
  4. ログイン完了後このウィンドウに戻ってください
 
ログインが完了したら Enter を押してください（再確認します）:
  1. 別の PowerShell ウィンドウを開く（install.bat のウィンドウはそのままにしておく）
  2. 表示されたパスの claude.exe を実行する
  3. Claude の画面が開いたら /login と入力して Enter
  4. 「Select login method:」画面が表示されたら 1 を入力して Enter
    Select login method:
      > 1. Claude account with subscription  · Pro, Max, Team, or Enterprise
        2. Anthropic Console account           · API usage billing
        3. 3rd-party platform                 · Amazon Bedrock, Microsoft Foundry, or Vertex AI
    ✅
    Cowork（Claude Desktop Pro）のサブスクリプションをお持ちの場合は必ず 1 番 を選択してください。
  5. ブラウザが自動で開くので「許可（Authorize）」または「承諾」をクリックしてログインを完了する
    ※ すでにブラウザで Claude にログイン済みの場合はボタンを押すだけで完了します
    ⚠️
    ブラウザが自動で開かない場合：
    PowerShell の画面に長い URL が表示されています。その URL をコピーしてブラウザのアドレスバーに貼り付けてください。承諾ボタンのある画面が開きます。
  6. install.bat のウィンドウに戻り Enter を押す → 自動で再確認されます
ℹ️
ログインが完了するまでこのステップは先に進みません。ログインが確認されると自動で STEP 5 へ進みます。
⚠️
「claude: コマンドが見つかりません」と表示される場合：
Cowork（Claude Desktop Pro）が正しくインストールされていないか、まだ一度も起動していない可能性があります。Cowork を起動してログインを完了してから install.bat を再実行してください。

Google サービスアカウント JSON の自動配置

install.bat が自動でコピーします

受け取った zip を展開すると、プロジェクトフォルダ内の secrets/ フォルダに JSON ファイルが含まれています。

nyseo-internal-link-agent/
└── secrets/
　　 └── nyseo-agent-xxxxxxxx.json　← ここに入っていれば OK
✅
JSON ファイルが secrets/ フォルダ内にあれば、install.bat が自動的に ~\.secrets\ へコピーします。手動での操作は不要です。
⚠️
JSON ファイルが見つからない場合は管理者にお問い合わせください。secrets/ フォルダ内に配置すれば install.bat が処理します。

環境変数の設定

入力が必要な箇所は 2 箇所のみです

入力が必要な箇所（全 11 ステップ中 1 箇所のみ）

① Google サービスアカウントのパス確認

STEP 6 で配置した JSON のパスが自動表示されます。合っていれば Enter を押すだけです。

━━━━━━ [7/11] 環境変数の設定 ━━━━━━   [7-1] Google サービスアカウント JSON のパス設定 デフォルト: C:\Users\<ユーザー名>\.secrets\agent-xxxxxxxx.json パスを入力（デフォルトのままなら Enter）: ← Enter を押す ✔ ファイルを確認しました ✔ GOOGLE_SERVICE_ACCOUNT を設定しました

上記以外（Python 確認・JSON 自動コピー・pip インストール・スタートアップ登録・ランナーサーバー起動）はすべて自動処理です。画面を見ながら待つだけです。
8

WordPress サイト情報の設定

WordPress 自動反映機能を使う場合に設定します（スキップ可）

WordPress REST API で記事を更新するため、サイトの URL・ユーザー名・アプリケーションパスワードを入力します。入力した情報は ~/.secrets/nyseo_sites.json に安全に保存されます。サイトはWordPress URL のドメイン名（例：example.com）をキーとして自動識別されます。

  1. WordPress サイト URL を入力する（例：https://example.com）
  2. WordPress ユーザー名 を入力する（ログイン名）
  3. アプリケーションパスワード を入力する（スペース区切りの文字列）
  4. 複数サイトを登録する場合は「Y」を入力して繰り返す
ℹ️
WordPress を使わない場合は N を入力してスキップできます。後から install.bat を再実行して追加することも可能です。

アプリケーションパスワードの発行手順

  1. WordPress 管理画面 → 「ユーザー」→「プロフィール」を開く
  2. ページ下部の「アプリケーションパスワード」セクションまでスクロール
  3. 任意の名前を入力して「新しいアプリケーションパスワードを追加」をクリック
  4. 表示されたパスワード（スペース区切り）をコピーして入力する
⚠️
アプリケーションパスワードは発行時の1回しか表示されません。必ずコピーしてから入力してください。
